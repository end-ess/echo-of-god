  • Android: open the APK to install it. The first time, allow “Install unknown apps” when your phone asks.
  • Mac: the file is on Google Drive. Open the link, click Download, and if Drive says it can’t scan the file for viruses, click “Download anyway”. Then unzip and drag the game into Applications. If macOS blocks the first launch, go to System Settings → Privacy & Security and click “Open Anyway”.
  • Windows: also downloads from Google Drive (click “Download anyway” if it can’t scan the file). Then unzip and run TheEchoOfGod.exe. If you see “Windows protected your PC”, click “More info → Run anyway”.
